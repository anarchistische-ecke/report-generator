# Report Generator (TGK01)

Консольное приложение для генерации отчетов в ТГК-1 из базы данных программного комплекса Взлет-СП4. Адреса для генерации отчетов берутся из таблицы EquipTGK01. Отчеты формируются в соответствии с правилами, изложенными в документе "Формат часовых архивов тепловычислителей для предоставления в Дирекцию по сбыту тепловой энергии ПАО «ТГК-1» филиала Невский Версия 2.0 от 29.11.2017"


## Build

```bash
./gradlew build
```

## Run (в продакшене run-report.bat)

```bash
--from 2025-08-20 --to 2025-09-22 --db-user Имя --db-pass Пароль --output C:\\reports
```

## Run (в среде разработки)

```bash
./gradlew run --args "--from 2025-08-20 --to 2025-09-22 --db-user Имя --db-pass Пароль --output C:\\reports"
```


### Options

- `--config` путь к конфиг файлу (default: `config/report.properties`)
- `--from` дата начала сбора данных (обязательно указывать, формат `yyyy-MM-dd`)
- `--to` конечная дата сбора данных, включительно (обязательно указывать, формат `yyyy-MM-dd`)
- `--db-url` JDBC URL (опционально, переписывает конфиг)
- `--db-user` имя пользователя SQL сервера (опционально, переписывает конфиг)
- `--db-pass` пароль SQL сервера (опционально, переписывает конфиг)
- `--output` директория для сформированных файлов (опционально, переписывает конфиг)
- `--contract` номер договора (опционально, переписывает конфиг)
- `--equip-id` можно указать конкретный EquipId, чтобы сформировать отчет только по нему
- `--equip-name` фильтр по названию прибора (SQL `LIKE`)
- `--param11..--param17` изменение шапки файла

## Notes

- Кодировка на выходе UTF-8.
- Имена файлов взяты из `Equip.name`.
- Параметры из блока опций можно прописать в конфиг, чтобы не указывать их каждый раз.
- Исправлено на уровне генератора отчетов нежелательное форматирование малых чисел в научной нотации (прим. 6.87776e-005), возникавшее при преобразовании значений из столбцов с типом float (приближённые типы) в таблицах тепловычислителей dbo.Table_*_Natural_Hour: перед записью в файл значения, пришедшие в строковом виде, проверяются на формат научной нотации (e/E) и при необходимости конвертируются через BigDecimal в обычную десятичную запись (toPlainString)

## Config

Скопируйте `config/report.properties.example` в `config/report.properties` и заполните свои значения.
Файл `config/report.properties` не должен попадать в git.
